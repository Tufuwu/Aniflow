# 第 5 话《命运的相遇》v2 录音标注

段号与 v2 口播稿一致。斜线是可用的气口，通常轻停即可。粗体是语义重音，用放慢和咬字体现。标注沿用原稿文字。对白可按角色语气读，段内的转述由旁白读。

第 14 段在「凯尔想」处从书中回到当晚。第 22 段在「至于」处由招待客人转入凯尔的内心盘算。第 26 段读完给伯爵留一点沉默，再读第 27 段。

| 段 | 断句与重音 | 语气 |
| --- | --- | --- |
| 01 | 城墙下，/凯尔答应给崔寒吃的。崔寒撑起身子，/一瘸一拐地跟了上来。**书里**，/崔寒揍了原主一顿，/还因此认识了一个人。凯尔想把那顿揍省了，/借这顿**晚饭**让两人照样见面。 | 开头平稳。讲完崔寒跟上来的动作，停半拍再进书中回忆。「晚饭」读出凯尔有了主意的轻快。 |
| 02 | 那只红猫凑过来，/贴着凯尔的靴子直蹭。凯尔平时不喜欢猫，/低头一看，/这只倒挺可爱。一抬眼，/崔寒正盯着他。凯尔只好蹲下来摸摸红猫，/临走还跟它说了声「下次再见」。 | 前半带点笑意。「一抬眼」后微停，看到崔寒时收住笑意。「下次再见」轻柔随口。 |
| 03 | 离开城墙，/凯尔放慢了步子，/好让脚上有伤的崔寒跟得上。快到伯爵府门口，/身后的脚步声**忽然停了**。 | 前半放缓，末句音量轻收，停半拍再回头。 |
| 04 | 凯尔回头问了声怎么了。崔寒一言不发，/还是盯着他看。凯尔心里直发毛。/这人该不会在掂量自己好不好杀吧？ | 第一句用旁白转述。最后一句像凯尔心里冒出来的念头，略压低，句尾轻抬。「好不好杀」连读。 |
| 05 | 「……不来吗？」 | 凯尔试探。开口前留半拍，整句轻短，尾音微抬。 |
| 06 | 崔寒又跟了上来。他进城是想替遇害的村民/求一场葬礼。**凯尔猜**，/崔寒肯跟到这儿，/兴许是想看看他能不能帮上忙。 | 讲葬礼时放慢、放稳。后半明确是凯尔的猜测，「兴许」轻带。 |
| 07 | 守卫认出凯尔，/紧张得喊了声「公、公子」，/连忙给他开门。 | 第一个「公」短而卡顿，第二个「公子」连起来，后面的旁白恢复正常。 |
| 08 | 进了府，/凯尔才发现，/老管家伦**居然真在等他**。伦笑着鞠躬，/问候完少爷，/目光就落到了崔寒身上。凯尔知道，/伦是个**暗杀者**，/多半看得出崔寒有多强。 | 「居然」带一点意外。「暗杀者」稍压低、读清，末句留着推测的口气。 |
| 09 | 崔寒也抬眼看了回去。两人一句话都没说，/夹在中间的凯尔已经觉得快擦出火星了。他咳了两声，/叫崔寒跟自己走。伦主动提出招待客人，/凯尔回了句「不用」。眼下让他们**打个照面**就够了。 | 对视两句稍慢，后半恢复节奏。「不用」短促平实。末句轻收，像凯尔心里的判断。 |
| 10 | 半路上，/副管家汉斯从门里探出头来。 | 旁白轻起，末尾留一拍给汉斯的声音进来。 |
| 11 | 「少爷！/您今天喝了酒，/竟然还能走回家？！」 | 汉斯真吃惊。「少爷」短亮，「竟然还能」稍落重，尾音微扬。 |
| 12 | 凯尔一抬酒瓶，/汉斯吓得往后一缩。凯尔把瓶子递过去，/让他收好，/临走还丢下一句，/下回就直接扔给他了。 | 抬瓶和后缩两拍读紧。最后一句仍是旁白转述，带一点凯尔随口撂话的劲儿。 |
| 13 | 凯尔领着崔寒去了厨房。厨师比克正在磨刀。/他是伦的儿子，/也是凯尔特意带崔寒来见的人。 | 磨刀一句稳住。点出父子关系后略停，「特意」读清，接回开场的盘算。 |
| 14 | 按《英雄的诞生》里的情节，/比克亲眼看见崔寒把原主揍了一顿，/见识了崔寒的本事，/才决定追随他。凯尔想，/今晚先让两人见个面，/兴许比克自己就能看出崔寒有多强。要是比克肯跟崔寒走，/说不定他父亲伦也会一起离开。凯尔就能过几天**清静日子**了。 | 先用平稳的旁白讲书里的因果。「凯尔想」重新起句，回到今晚的打算。「要是」和「说不定」轻带，想到清静日子时放松。 |
| 15 | 想到这儿，/凯尔把手往崔寒肩上一搭。 | 从心里的盘算转到动作，语气轻一点。动作句尾稍收，再接吩咐。 |
| 16 | 「给他弄点吃的。」 | 凯尔对比克说，像一句家常吩咐。整句连读，平落。 |
| 17 | 比克举着刀抬头。/「……什么？」 | 旁白收住，再换比克。对白前停半拍，音量略低，短短一问。 |
| 18 | 「先把刀放下再说话……/给他弄点吃的，/他饿了。」 | 先低声催比克放刀，停半拍，再把吩咐说清。「他饿了」短短收住。 |
| 19 | 比克应了一声。/凯尔松了口气。崔寒见到了比克，/还顺带见了伦。今晚的事办妥了，/他这才想起自己的晚饭。 | 「松了口气」后放松。提到自己的晚饭时带出一点笑意，准备接下一段。 |
| 20 | 「给我也弄一份，/我也饿了。全都要**最贵、最高级**的。」 | 凯尔理直气壮地点菜。前句随口，「最贵」「最高级」读得清楚、有节奏。 |
| 21 | 想起昨天那块牛排，/凯尔又夸了句比克手艺好。比克听得一愣，/凯尔已经催他快点做，/转身出了厨房。 | 夸手艺带一点真心。比克愣住留一个短拍，凯尔出门的动作轻快收掉。 |
| 22 | 汉斯追上来问那位客人该怎么安置。凯尔说，/崔寒是他的客人，/怎么招待就让汉斯看着办。至于比克能不能看出崔寒的本事，/凯尔还有个后手。实在不行，/就让崔寒揍个**别人**，/再叫比克亲眼看看。 | 前半像交代家务。「至于」另起，把声音放轻，转进凯尔的盘算。「别人」点一下笑点。 |
| 23 | 凯尔又吩咐了一句，/自己的晚饭做好了/直接送进房里，/省得他再出来一趟。 | 全段用旁白转述，念出凯尔嫌麻烦的随意劲儿。「省得」轻带。 |
| 24 | **夜深了**，/汉斯去书房向伯爵汇报。凯尔今天/先去了布林商团那位庶子比鲁斯开的茶店，/回来时带了个身份不明的少年。还有一件事。/少爷今天喝过酒，/回府时人还**清醒**着。 | 换到书房，语速放慢。「布林商团」和「比鲁斯」各自连读。「还有一件事」后留半拍，最后压实「清醒」。 |
| 25 | 汉斯问要不要派人跟着少爷。伯爵说不用。/只要凯尔还在领地里，/他做的事就还在伯爵的掌控之中。汉斯照旧留意凯尔的动静，/有事来报告就行。 | 汉斯的提议轻带，伯爵的答复沉稳简短。「照旧」放稳，吩咐完收声。 |
| 26 | 汉斯鞠躬应下。/伯爵托着下巴，/沉默了一会儿。 | 语速放慢，句末留半秒左右。 |
| 27 | 凯尔变了。 | 贴伯爵的视角，低声落定。「变」略重，「了」轻收，句末留一拍。 |

### 变调与轻声

- 「一瘸一拐」读 **yì qué yì guǎi**，「一抬眼」读 **yì tái yǎn**，「一场」读 **yì chǎng**，「一言不发」读 **yì yán bù fā**，「一看」读 **yí kàn**。
- 「一顿」读 **yí dùn**，「一份」读 **yí fèn**，「一愣」读 **yí lèng**，「一趟」读 **yí tàng**，「一会儿」读 **yí huìr**。
- 「一句话」读 **yí jù huà**，「一句」读 **yí jù**，「一缩」读 **yì suō**，「一搭」读 **yì dā**，「一件事」读 **yí jiàn shì**。
- 「不用」读 **bú yòng**，「不行」读 **bù xíng**。「好不好」「能不能」「要不要」中间的「不」可轻读 **bu**。
- 「少爷」读 **shào ye**，「老管家」读 **lǎo guǎn jiā**。「给他弄点吃的」连读，「的」读轻声 **de**。
