# 第 6 话《血腥味的少年》v1 录音标注

段号对应 v1 口播稿。斜线表示可用气口，遇到标点只停一次。粗体表示语义重音，稍微放慢或咬清即可。

第 1 段先讲次日的关门，第 2 段倒回前一晚，第 4 段再切到清晨。第 10 段在「一声不吭」后留半拍，再接关门的动作。第 23 段从空杯转到罗恩的怀疑，第 24 段由崔寒出声打断。

| 段 | 断句与重音 | 语气 |
| --- | --- | --- |
| 01 | 凯尔昨晚借着请崔寒吃饭， / 让他和厨师比克见了一面。他以为这事办完了， / 结果第二天一开门， / 崔寒就站在门口， / 吓得他**砰的一声**又把门关上了。崔寒一大早守在这儿， / 到底有什么事？ | 前情平稳。开门、关门提速，「砰的一声」连读。末问带好奇，留半拍。 |
| 02 | **前一晚**， / 伯爵还在书房琢磨凯尔的变化。儿子看上去跟平时一样， / 可照汉斯的说法， / 他这回喝了酒还能**清醒着回府**， / 又带了个客人回来。伯爵吩咐汉斯去查查布林家的庶子比鲁斯。凯尔白天去过的茶店， / 就是他开的。 | 时间倒回时稍停。汉斯的汇报仍用旁白，查比鲁斯一句干脆收住。 |
| 03 | 伯爵走到窗边。最近整个大陆的动静都**不寻常**。家里一向是先守住手里的家业， / 再慢慢往外扩张。伯爵只盼孩子们往后能过得安稳。他转过身， / 心里有了主意。 / **城墙**该修一修了。 | 伯爵思量局势时放慢，说到孩子时放柔。末句稳稳落定。 |
| 04 | 第二天早上， / 凯尔刚醒， / 胃里就一阵难受。偏偏罗恩又端来一杯**柠檬水**。他抬眼一看， / 老管家脖子上缠着**绷带**。 | 转回早晨。「偏偏」带点嫌弃，发现绷带后收住笑意。 |
| 05 | 「你脖子**受伤**了？」 | 凯尔随口问，带一点意外，尾音微抬。 |
| 06 | 「您是在**担心我**吗？」 | 罗恩轻声带笑，略有试探，「吗」轻收。 |
| 07 | 凯尔接过杯子， / 说自己只是觉得绷带有点碍眼。罗恩笑着说， / 是让一只伸爪子的**小猫**挠了。凯尔一边喝， / 一边在心里嘀咕， / 指不定是哪个**倒霉蛋**。 | 前两句用旁白转述。末句贴凯尔的内心，放轻吐槽。 |
| 08 | 凯尔喝完把杯子递回去， / 说外头有人伺候， / 自己出去就行。手都搭上**门把**了， / 罗恩忽然问了一句， / 柠檬水好喝吗？ | 门口动作读清，问味道时稍慢，转述中带一点罗恩的客气。 |
| 09 | 「很、 / **很好喝**。」 | 第一个「很」短促，微微卡一下。「很好喝」连读，像硬着头皮应付。 |
| 10 | 凯尔说完把门一拉。 / 崔寒就站在门外， / **一声不吭**。 / 凯尔赶紧把门关上， / 按着胸口喊罗恩。 | 开门后先让沉默落地，再突然提速关门。「喊罗恩」用旁白。 |
| 11 | 罗恩这才笑着解释。 / 「昨晚那位客人一直在门外等您。 / 我让他回房间等， / 他说一定要见您。刚才您开门太快， / 我**没来得及说**。」 | 第一句旁白，随后换罗恩。礼貌从容，末句轻轻带笑。 |
| 12 | 凯尔听得直冒汗。从递柠檬水到问味道， / 说了这么半天， / 现在**倒说**没来得及。 | 凯尔的内心吐槽，中段略快，「倒说」稍重。 |
| 13 | 他重新打开门， / 问崔寒有什么事。崔寒低着头， / 嘴里蹦出**两个字**。 | 前句平稳，后半放轻，说完留半拍。 |
| 14 | 「**饭钱**。」 | 崔寒低声、短促，两字连读。读完稍停，让没听清的反应接上。 |
| 15 | 凯尔没听清， / 崔寒就抬起头又说了一遍。他愿意**干活抵饭钱**， / 叫他做别的事也行。 | 换回旁白。后半读出崔寒的认真，「干活抵饭钱」连读。 |
| 16 | 凯尔抱着胳膊， / 回了句不用。他心想， / 一顿饭而已， / 自己哪敢真使唤这位**书里的主角**。崔寒的手攥了一下， / 又开了口。 | 凯尔的内心带点自嘲。念到崔寒攥手时收住笑意，末尾短停。 |
| 17 | 「其实， / 我想**拜托**你一件事。」 | 崔寒比说饭钱时更郑重。「其实」稍犹豫，后半说稳。 |
| 18 | **凯尔猜**， / 他多半是想为海里斯村的事求助。崔寒进城， / 就是想替遇害的村民办一场**葬礼**。凯尔让他有事直接找副管家汉斯， / 又抬手搭住罗恩的肩， / 交代他好好听崔寒说。既然是自己的客人， / 能帮的就尽量帮。 | 先点明是谁在猜。提到葬礼时放稳，恢复日常语速交代汉斯和罗恩。「为海里斯村的事求助」连读。 |
| 19 | 崔寒愣了一下。 / 「可你连**我是谁**都不知道。」 | 先旁白，再换崔寒。对白带困惑，末尾轻落。 |
| 20 | 「帮助比我弱势的人 / 还需要**理由**吗？」 | 凯尔平实地反问，「比我弱势的人」连着读，句尾轻收。 |
| 21 | 凯尔说， / 事情要是真难办， / 汉斯自然会拒绝。他说完便转身走了。今天要花钱的地方还多着， / 他得赶紧去领**零花钱**。 | 前两句平实。转身后略加快，提到零花钱时放松一点。 |
| 22 | 罗恩在身后应下， / 说一定尽力。凯尔回头瞥了一眼， / 心想**正好**， / 让他们自己打交道去吧。 | 罗恩的答复用旁白转述。到「心想正好」贴近凯尔，像松了口气。 |
| 23 | 望着凯尔走开， / 罗恩想起少爷一向讨厌酸的。他低头看了眼**空杯**。刚才那杯柠檬水， / 凯尔喝了个干净， / 还说好喝。罗恩摸着脖子上的绷带， / 心想， / 这小子是在**害怕**。他到底知道了些什么？ | 空杯处放慢，「还说好喝」带疑惑。摸绷带后压低，末问像罗恩在心里问自己。 |
| 24 | 「喂， / **带路吧**。」 | 崔寒出声打断罗恩的思绪。「喂」短，后半低而干脆。 |
| 25 | 罗恩瞥了崔寒一眼。刚才还老老实实要抵饭钱的少年， / 在罗恩看来， / 浑身都是**人血**的味道。那副天真的样子， / 他可不信。 | 长句在「少年」后换气。「人血」读清，最后一句放冷，落在罗恩的判断上。 |
| 26 | 罗恩笑了笑。 / 「好啊， / **跟我来**。」 | 旁白后换罗恩。「好啊」温和，「跟我来」简短平落。 |
| 27 | 崔寒回头看了一眼凯尔的背影， / **转身**跟上了罗恩。 | 放慢，旁白自然落地，句末给最后一个画面留半拍。 |

### 变调与轻声

- 「一面、一阵、一遍、一下、一句、一件」的「一」读 **yí**。「一开门、一声、一杯、一只、一边、一拉、一直、一场、一眼」的「一」读 **yì**。「一定」读 **yí dìng**。
- 「不用、不信」读 **bú yòng、bú xìn**。「不知道、不吭」读 **bù zhī dào、bù kēng**。
- 「这儿」读 **zhèr**。「好啊」可自然连成近似 **hǎo wa**，尾音放轻。
- 「外头、少爷、使唤、动静」口播可读 **wài tou、shào ye、shǐ huan、dòng jing**。轻声音节短收。
