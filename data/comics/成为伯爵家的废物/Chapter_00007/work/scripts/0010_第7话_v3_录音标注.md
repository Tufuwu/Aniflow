# 第 7 话《致命旅程》v3 录音标注

段号对应 [v3 录音审校版](0010_第7话_漫画讲解稿_v3_录音审校版.txt)。斜线是可用的气口，和标点重合时只停一次。加粗处稍放慢或咬清。省略号和段落间的停顿按语气掌握。

## 时间、场景和视角

| 段落 | 怎样接 |
| --- | --- |
| 1–2 | 第 1 段从上一话领零花钱接到晚间的王室邀约。第 2 段用「这事还得从白天说起」退回当天白天。 |
| 5–10 | 「下山去买面包」接「到了街上」。买面包时短暂转到旁观的比克，再用「回到山坡上」跟回凯尔。 |
| 10–15 | 红发弟弟挡路，灰发女孩说「你不能死」。接着是凯尔穿越前的回忆，「眼前的女孩」拉回当下。凯尔答完，回到古树下。 |
| 17–19 | 「到了约好的时候」回扣第 4 段父亲让凯尔晚上去书房。凯尔进屋后，才继续揭晓王室邀约的内容。 |
| 20–23 | 广场袭击和挨揍都出自凯尔读过的《英雄的诞生》。第 20 段末是凯尔对将来的判断，第 21 段看向身边的巴森。第 22 段的「可如今」结束第二次回想，回到书房。 |
| 24–33 | 出书房后一直在走廊。先听巴森说话，再由汉斯打断凯尔的盘算。最后「饭钱」前后各留半拍，接崔寒的收尾画面。 |

## 逐段断句和语气

| 段 | 断句与重音 | 语气 |
| --- | --- | --- |
| 01 | 上一话，/ 凯尔托罗恩和汉斯帮崔寒，/ 自己赶着去领零花钱。那笔钱，/ 他打算拿去买面包喂古树。可等他忙完回府，/ 父亲却要他去**都城**参加王室的活动。凯尔一听，/ 鸡皮疙瘩都起来了。 | 前情轻快，落到「都城」时收住笑意。最后一句放低，留半拍再回到白天。 |
| 02 | 这事还得从**白天**说起。/ 凯尔扛着布袋来到树下，/ 往洞里倒了几个面包。面包刚落下去，/ 洞里就传来一个少女的声音。 | 首句重新起调。念到「少女的声音」放慢，给下一句留个空。 |
| 03 | 「**还要**，/ 我还要……」 | 少女声低一点。第一个「还要」短，第二个稍拖，尾音渐收。 |
| 04 | 凯尔想起书里提过，/ 那个活活饿死的人，/ 曾是侍奉神明的神女。她留下的怨念还在洞里。凯尔得接着喂，/ 才有机会拿到**不破之盾**。父亲让他晚上去趟书房，/ 他得抓紧了。 | 前两句稳一点，像顺着声音想起书里的来历。提到晚上赴约时略提速。 |
| 05 | 凯尔从树下出来，/ 瞥见墙边的灰发姐姐和红发弟弟。两个孩子正捧着面包，/ 一看他走过来，/ 嚼到一半就呆住了。凯尔咂了下嘴，/ 先下山去买面包。 | 见到姐弟时放轻，最后一句接着动作顺下去。 |
| 06 | 到了**街上**，/ 凯尔想另找一家面包店。昨天那家已经被他买空了，/ 还得等人家重新做。正找着呢，/ 街边就有个大婶喊住他，/ 说自己家也有很多面包。 | 街头段语气松一点。「喊住他」微抬，带出大婶主动招揽的反应。 |
| 07 | 凯尔抛过去一枚钱币，/ 让她把现成的面包全包起来。大婶转眼就搬来一大袋，/ 还说自家能做更多。旁边又有人喊了一声，/ 说他家做得**更多**。 | 动作句稍快。「更多」点一下，让两家争着做生意的劲儿出来。 |
| 08 | 凯尔听了，/ 当场又订下一麻袋。他算了算，/ 明天只要去三个地方收面包，/ 这事就好办了。 | 像随口算账。最后一句轻松落下。 |
| 09 | **凯尔**觉得这趟买得挺顺。/ 躲在一旁的**比克**却看得一头雾水。他想起父亲罗恩说过，/ 这位少爷挺有意思。比克起初没往心里去，/ 看久了才觉得，/ 凯尔和那个黑头发的小子一样，/ 都值得再瞧瞧。 | 第一句跟着凯尔，第二句在「比克」处换视角，声音略压低。罗恩的话继续用旁白转述。 |
| 10 | 等凯尔扛着面包**回到山坡上**，/ 墙边的姐弟还在。他给灰发女孩的却是一小瓶**药草**。女孩捧着瓶子发愣，/ 凯尔已经催他们让路了。红发弟弟张开胳膊挡住他，/ 灰发女孩在旁边开了口。 | 落重在「药草」，随后放慢。最后一句留半拍给女孩开口。 |
| 11 | 「你**不能死**……」 | 灰发女孩轻声劝阻，尾音放轻，留一点犹豫。 |
| 12 | 凯尔愣了一下。/ 这句话让他想起穿过来以前的事。那时候，/ 他是个孤儿。小时候，/ 有人同情他，/ 他有时还会把人家的好意往坏处想。长大以后才明白，/ 看见别人过得难，/ 想伸把手，/ 本来也用不着什么理由。 | 整段放慢。孤儿经历平实地讲，「用不着什么理由」自然收住。 |
| 13 | **眼前的女孩**走路一瘸一拐。凯尔看着不好受，/ 又嫌照顾这俩孩子麻烦。最后，/ 他只说了一句。 | 「眼前」带回当下。「嫌麻烦」轻带一点自嘲，末尾留半拍。 |
| 14 | 「我**不会死**的。」 | 凯尔平静地回答，既简短也让孩子安心。「的」轻落。 |
| 15 | 凯尔回到**古树下**，/ 洞里的声音还在讨吃的。他拎起袋子，/ 又往里倒。这回，/ 洞里的黑色总算浅了一些。/ 钱没白花。 | 倒面包带回动作节奏。「钱没白花」像凯尔松了口气，轻轻一收。 |
| 16 | 他起身一看，/ 墙边的两个孩子已经没影了。凯尔心想，/ 看不见那个受伤的小家伙，/ 心里果然好受一点。刚松口气，/ 脚边就传来两声**猫叫**。 | 前半像自我安慰。「猫叫」前后略顿，给下一段揭晓。 |
| 17 | 是昨晚喂过的那两只猫，/ 一灰一红。凯尔还纳闷，/ 它们是不是记住了自己。他摆摆手，/ 想着还是少管点闲事。 | 认出猫后轻一点。末句像凯尔随口劝自己，音量放下来。 |
| 18 | 到了**约好的时候**，/ 凯尔回府去见父亲。进了书房，/ 弟弟巴森也在。凯尔听完父亲的话，/ 还以为自己听岔了，/ 忍不住请父亲再说一遍。 | 和前段隔半拍，重起一句。进书房后语速放慢，最后带出凯尔的意外。 |
| 19 | 伯爵德勒特说，/ 王室要办一场大活动，/ 请了各家贵族的孩子。从去年起，/ 这种场合都由巴森出席，/ 这回原本也打算让他去。可伯爵临时改了主意，/ 想让凯尔这个**长子**代表家族去。 | 稳稳转述。把「原本」和「改了主意」念清，后半句落在「长子」。 |
| 20 | 凯尔心里**咯噔**一下。/ 《英雄的诞生》里写过，/ 神秘组织在都城的广场发动了袭击。崔寒出手救下许多百姓，/ 也因此和皇太子结下了交情。凯尔越想越觉得，/ 自己这一趟多半会撞上那场袭击。 | 进书中情节前轻停，压低一点，放慢讲清崔寒的作用。最后一句回到凯尔的判断，「多半」轻带。 |
| 21 | 凯尔转眼看了看**身边的巴森**。只要开口让弟弟照老样子去，/ 自己或许就能躲过这桩麻烦。可他明知道都城可能出事，/ 那句话怎么也说不出口。 | 「身边」把注意力拉回书房。最后一句压低，念出想开口又收住的犹豫。 |
| 22 | 偏偏伯爵又说，/ **五天后**出发就行。凯尔一听这个日子，/ 算是明白了。原书里的凯尔，/ 到了出发那天已经挨了崔寒一顿揍，/ 被人抬回伯爵府，/ 哪儿也去不了。**可如今**，/ 那顿揍躲过去了，/ 去都城的差事反倒落到了他头上。 | 「五天后」读清，停一下再回想原书。到「可如今」重新起调，最后带一点凯尔的无奈。 |
| 23 | 伯爵还笑着劝他，/ 巴森接手以前，/ 这类场合本来就是凯尔去的。就当找找以前的感觉。凯尔听得更慌了，/ 只说自己得先考虑一下。 | 前半是带笑的转述，说「更慌了」时换回凯尔的反应。 |
| 24 | 出了书房，/ 凯尔听见巴森在身后叫他，/ 停下了脚步。 | 从室内移到走廊，末尾留半拍，像听见叫声后站住。 |
| 25 | 「哥，/ 你没理由不去参加活动。」 | 巴森平静直说。「哥」略停，后半连着说完，平落。 |
| 26 | 凯尔听完更头疼了。巴森早就像个继承人一样替家里出面。等弟弟接手领地，/ 他才有清闲日子过。真要换巴森去，/ 万一弟弟回不来，/ 往后怎么办？自己好歹知道书里的情节，/ 真走一趟，/ 还有几分把握平安回来。 | 开头像凯尔心里叹气。说到巴森可能回不来时放慢，最后一句稳下来，读出他在权衡。 |
| 27 | 凯尔还在走廊上盘算，/ **汉斯**就找了过来。汉斯刚提到今天那位客人托他办的事，/ 凯尔就打断了他。看汉斯的表情，/ 凯尔猜崔寒托办的事已经解决得差不多了。 | 「汉斯」处稍提音，打断内心盘算。末句压平，「猜」读清。 |
| 28 | 真要去都城，/ 凯尔得先找个帮手。原书里拦下袭击的崔寒，/ 这会儿就在府上。 | 把思路从汉斯的汇报转到凯尔的决定。末句轻轻点出「就在府上」。 |
| 29 | 「去把那位客人请过来。」 | 凯尔平常吩咐，简短干脆。 |
| 30 | 汉斯听得一愣。/ 凯尔又补了一句。 | 先顿一下给汉斯的反应，第二句轻带，接凯尔对白。 |
| 31 | 「他要是不来，/ 你就跟他说两个字。」 | 凯尔像突然想起一件事，语气轻。句末留半拍。 |
| 32 | 「**饭钱**。」 | 两字连读，轻点重音，短短落下。后面留半拍。 |
| 33 | 「有件事能抵他的饭钱，/ 让他过来。」 | 凯尔随口交代。前半不拖，末句收干净。 |

## 普通话字音

| 位置 | 词语 | 口播读音 |

| 全篇 | 凯尔、崔寒、罗恩、汉斯、比克、德勒特、巴森 | kǎi ěr、cuī hán、luó ēn、hàn sī、bǐ kè、dé lè tè、bā sēn |
| 第 1、18–19 段 | 都城、都起来了、都由、以为、听岔了 | **dū** chéng、**dōu** qǐ lái le、**dōu** yóu、yǐ **wéi**、tīng **chà** le |
| 第 2–4、6、23、28 段 | 还要、还在、还得等、还得从白天说起、得接着喂、得先考虑、得先找 | 本话的「还」读 **hái**。表示需要的「得」读 **děi**。 |
| 第 2、15、22 段 | 倒面包、往里倒、反倒 | 都读 **dào**。 |
| 第 4–6、9–10 段 | 曾是、侍奉、瞥见、咂嘴、重新、灰发、红发、头发、发愣 | **céng** shì、shì fèng、**piē** jiàn、**zā** zuǐ、**chóng** xīn、huī **fà**、hóng **fà**、tóu fa、**fā** lèng |
| 第 3、4、17、20、21、26、28 段 | 还要、不破之盾、想着还是、多半会、只要、好歹、这会儿 | hái yào、**bú** pò zhī dùn、xiǎng zhe hái shì、duō bàn huì、**zhǐ** yào、hǎo **dǎi**、zhè **huìr** |
| 第 6–9、12、23、27、30 段 | 找着呢、买得顺、做得更多、看得一头雾水、过得难、听得更慌、解决得差不多、听得一愣 | 「找着呢」的「着」读 **zhe**，「过得难」的「难」读 **nán**。这里作补语标记的「得」都读轻声 **de**。 |
| 第 12、13、17、19 段 | 长大、长子、用不着、瘸、两只猫、只说了一句、一场活动 | **zhǎng** dà、**zhǎng** zǐ、yòng bu **zháo**、**qué**、liǎng **zhī** māo、**zhǐ** shuō le yí jù、yì **chǎng** huó dòng |
| 第 6、10、20、22 段 | 买空、扛着、咯噔、挨了一顿揍、差事、哪儿也去不了 | mǎi **kōng**、**káng** zhe、**gē dēng**、**ái** le yí dùn zòu、**chāi shi**、nǎr yě qù bu **liǎo** |
| 第 16、19–20、22、26 段 | 好受一点、伯爵、发动、出发、领地 | hǎo shòu yì diǎn、bó **jué**、**fā** dòng、chū **fā**、lǐng **dì** |

- 「一看、一大袋、一下、一句、一趟、一顿、一愣」读 **yí**。「一枚、一麻袋、一头雾水、一小瓶、一场、一点、一瘸一拐、一灰一红」读 **yì**。「一声、一半、一遍」分别读 **yì shēng、yí bàn、yí biàn**。
- 「不会死、不去、不破」的「不」在四声前读 **bú**。「不能、不好受、要是不来」读 **bù**。「回不来、去不了、看不见、说不出口」中间的「不」可自然轻读 **bu**。
- 「疙瘩、胳膊、差事、交情、主意、地方、时候、纳闷」口播读 **gē da、gē bo、chāi shi、jiāo qing、zhǔ yi、dì fang、shí hou、nà mèn**。前七项的末字轻收。
