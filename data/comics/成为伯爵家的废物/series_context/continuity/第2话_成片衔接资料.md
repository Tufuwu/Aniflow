# 第2话《设下的诱饵》成片衔接资料

对应视频第 3 集，漫画素材编号 `0005`。以 v2 最终口播稿及纯人声成片为准。最终口播用的是「茶只要不苦」。

## 可直接沿用的前情

凯尔算出崔寒即将来到威思顿，便独自进了「茶香诗语」，在能望见城门的三楼等人。茶馆老板比鲁斯收了他的金币。比鲁斯嫌一百万格伦太多，凯尔让他把多的算作小费。

凯尔果然看到崔寒被守卫拦下，随后转身离开。按他读过的《英雄的诞生》，崔寒会等到天黑再翻墙进城，后来撞上醉酒的原主。原主侮辱遇害村民，才招来那顿狠揍。眼下离天黑还有时间，凯尔让比鲁斯留着座位，先出门准备能自保的远古之力「不破之盾」。本话停在凯尔站在面包摊前，想到取盾需要先准备诱饵。

| 6–14 | 凯尔一进门，茶客安静下来。比鲁斯笑着迎客，凯尔认出他是个有钱人家的庶子。凯尔点茶和小说，亮出金币，让比鲁斯把多的算作小费。 |
| 15–20 | 三楼看得见城门，凯尔来此是为了等崔寒。按他记得的小说，崔寒要向领主报告村子遭屠的事，希望为村民办一场葬礼。醉酒的原主出言侮辱死者，因此挨揍。 |
| 21–24 | 当下确实发生的是崔寒在城门口被守卫拦住，然后转身离开。查身份牌是凯尔的猜测，夜里翻墙及与原主冲突是凯尔记得的原小说走向。 |
| 25–28 | 凯尔让比鲁斯留位，出门准备自保。茶客惊讶他居然什么也没砸，凯尔在门外听到了。 |
| 29–32 | 凯尔记得大陆还会爆发战争，想找一种护身又低调的力量。他看中能形成无形护盾的远古之力「不破之盾」，在面包摊前停步，打算先备诱饵。 |

## 人物和章末状态

- **凯尔**从茶馆三楼远远看见了崔寒。两人尚未当面交谈，原主挨揍的情节只在回忆里出现。
- **崔寒**已到威思顿城门，被拦后离开。成片未交代他离开城门后的下落。
- **比鲁斯**已在本话具名，身份是「茶香诗语」老板、有钱人家的庶子。凯尔说还会来，临走也请他保留座位。
- **不破之盾**已交代名称和防护作用，凯尔尚未得到它。章末只给出面包摊和准备诱饵的打算，具体用途与取盾过程悬而未决。

## 成片口径

- 一百万格伦出现在茶馆场景，是比鲁斯惊讶时说的数。父亲戴鲁此前给了凯尔多少钱，口播没有报数。
- 茶馆门口的随行仆人在本话口播中未具名。
- 「茶只要不苦」以最终成片为准。场景中的消费和反应以本话口播为准。
