# 配音导演与试听审核

当前默认旁白为用户选定的云希 `zh-CN-YunxiNeural`，基础语速 `+35%`、音调 `-2Hz`。云希合成后应用 `yunxi_fast_warm_v1`：增强低频厚度、适度削减浑浊感、轻量压缩及双遍响度归一化（-18 LUFS，峰值上限 -2 dBTP）。参数与已选试听一致；其他声音及 ElevenLabs 不应用此后处理。样片预览、基础 TTS 和配音试听共用该处理，缓存标识包含完整处理参数。逐句表演计划仍可在基础语速上调整节奏。

## 使用流程

打开现有 `/shot-review` 工作台，完成文案审核与选镜后，进入“配音导演与试听”。

第四阶段后直接人工审核锁定的文案，须完成本页的配音试听与审核，才能生成时间轴和导出。

1. 选择固定主播风格：悬疑讲述、热血爽文或冷面吐槽。默认勾选“AI 根据剧情标注”，使用现有 StoryModel 配置读取本段事件与因果前提。取消勾选则生成明确标注的规则草案；模型失败不会悄悄降级成规则结果。
2. 检查逐句计划：原文只读，语气、情绪强度、语速意图、重音词、额外停顿及理由可编辑。重音词必须来自对应原句；情绪依据只能引用本段已有事件。修改自动锁定此段计划，AI 重跑保留锁定计划及已选配音。
3. 选择语音引擎及声音。ElevenLabs 支持 v4/v3 表演标签，推荐先用 v4；通过声音列表选择自己的 voice ID。密钥可通过 `ELEVENLABS_API_KEY` 配置，或在页面输入后仅保留于服务进程内存，不进入项目文件和审核历史。
4. 生成本段试听，或生成新的试听版本。新版本保留旧文件和选定配音。“三种风格对比试听”会为同一段原文生成3份规则草案预演，明确显示来源；不会自动覆盖当前计划或选定版本。ElevenLabs 试听会调用付费服务。
5. 选用一份试听及其表演计划。如果切换到不同计划，需重新审核计划。试听音频并勾选确认无漏读、错读或标签被念出，再“审核并锁定这份配音”。
6. 所有段落通过配音审核后，使用“采用已审核配音安排时间轴”。字幕优先按实际合成语义段的样本边界安排，语义段内部按短语分配。镜头和最终视频时长使用合成后音频，额外停顿计入时长。

启用配音导演后，旧的基础 TTS 排轴不会绕过配音审核。镜头审核和文案审核仍独立生效。尚未启用配音导演的旧项目保留原流程。

## 能力边界

- **ElevenLabs v4/v3**：由适配器将语气、强度、语速和重音意图编译为声音标签。只把原文及允许的表演提示送给 TTS，剧情依据和审核理由不会被朗读。声线能否自然执行指令仍需试听；中文重音及语速意图不承诺精确数值效果。
- **Edge 基础预演**：执行语速和额外停顿，原文中不会夹入 ElevenLabs 标签。它不执行情绪或重音，页面和音频版本都会明确标识。
- **精确停顿**：以48kHz单声道音频插入额外静音，保留每段语音及停顿的样本边界。它是额外停顿；模型自然生成的句末停顿仍可能存在。缓存使用 WAV 保存精确边界，最终视频统一输出 AAC。
- **自然连贯性**：按 AI 或人工确认的完整语义段合成，向 ElevenLabs 传递相邻原文作为上下文。避免逐字合成；过度拆分仍可能让听感断裂，需在计划审核时调整。
- **音频检查**：完整解码、非静音及疑似削波检测始终执行。漏读、错读、标签误读可通过可选转写辅助核验，但最终始终要求人工试听确认，不自动替用户通过审核。

## 可选转写核验

安装 `faster-whisper` 后，通过 `VOICE_ASR_MODEL` 指定本地模型路径或模型名。设置模型名可能在首次使用时下载模型；推荐使用已下载的本地模型目录。

```powershell
python -m pip install faster-whisper
$env:VOICE_ASR_MODEL = 'D:\models\faster-whisper-small'
```

不配置时，页面显示“未启用自动转写，需人工核对原文”。启用后比较标准化的原文与转写文本，保留差异记录；转写本身也可能误识别，发现差异后必须填写人工试听结论才能审核。此比较不是情绪质量打分。

## 新增模块与数据

- `voice_director.py`：风格、AI/规则计划、原文及证据校验、标签编译。
- `voice_audio.py`：语义段合成、精确静音、样本时间边界、基础音质及可选转写。
- `voice_pipeline.py`：独立计划与试听版本、人工锁定、选择及审核，复用现有剪辑版本存储。
- `voice_review.js`：配置、逐句编辑、三种风格试听和人工确认。

剪辑版本新增 `voice_direction`、`voice_samples`、`voice_selected`；音频缓存在现有 `editing/media/audio` 中以独立内容键保存。缓存键包含模型、声音、表演计划、语速参数和版本；生成新试听时使用独立键。导出 manifest 保留配音计划、选定版本和试听核验报告。
